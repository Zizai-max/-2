# 简历与联系二维码更新设计说明

## 目标

在现有作品集首页联系区中更新最新版简历，并把微信二维码放入联系信息右侧的指定区域，同时保持现有深色视觉、路由、内容结构和 GitHub Pages 部署方式不变。

## 方案

- 用用户提供的 `Group 2147229730.png` 原文件替换现有 `public/downloads/zhu-xingmeng-resume.png`，继续复用当前“下载简历”链接和文件名，不压缩、不改尺寸。
- 将用户提供的 `image 5939.png` 原文件复制为 `public/portfolio/pages/wechat-contact-qr.png`，禁止引用临时目录或外部磁盘路径。
- 保留 `.home-contact-links` 原有左右两栏结构；仅把左侧联系信息区域改为“文字信息 + 二维码”的内层网格，右侧下载入口保持不变。
- 二维码使用原始正方形比例，桌面端清晰展示，移动端缩小但不低于可扫描尺寸；使用白色底和现有圆角/边框变量，避免与深色背景混在一起。
- 邮箱仍可点击，手机号文字不变；二维码补充明确的替代文本。

## 响应式与验收

- 桌面端二维码位于邮箱、手机信息右侧，不遮挡文本或下载入口。
- 移动端联系区仍为单列，左侧内层保持文字与二维码并排；窄屏时允许文字自然换行且不出现横向滚动。
- 静态导出 HTML 必须包含稳定二维码路径、新版简历下载路径和二维码替代文本。
- 运行现有 lint、test、build，并在本地预览检查首页联系区桌面端与移动端。
