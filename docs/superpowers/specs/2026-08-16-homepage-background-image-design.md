# 首页首屏背景图片替换设计说明

## 目标

将用户提供的 `image 2692.png` 放在首页首屏最底层，完全替换当前远程视频背景。

## 约束

- 不移动、删除或重排导航、标题、个人信息、页脚提示等任何现有元素。
- 保留当前深色遮罩、颗粒、光带、光标交互和所有现有层级效果。
- 不修改首页以外的页面、内容、路由或部署配置。
- 图片按原文件复制，不压缩、不改色、不重新裁切源文件。

## 实现

- 将源图复制到 `public/portfolio/pages/home-hero-background-2026.png`。
- 用一个仅作装饰的图片元素替换现有视频元素，并继续占用原视频所在的最底层层级。
- 图片使用 `width: 100%`、`height: 100%` 和 `object-fit: cover` 填满首屏，避免拉伸。
- 图片保持居中定位；在窄屏下仅由浏览器进行响应式裁切，不改变其他元素的位置。

## 验证

- 首页静态输出包含新背景路径，不再包含旧视频地址或视频元素。
- lint、TypeScript 检查、测试、正式构建和 `git diff --check` 通过。
- 变更范围仅包含背景图片、首页背景标记、对应样式、测试和本说明。
- 推送后核对 GitHub Actions、GitHub Pages 和线上首页中的新背景路径。
